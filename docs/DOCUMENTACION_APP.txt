DOCUMENTACIÓN COMPLETA DEL PROYECTO AppTrabajadores PARA LA APP "FICHAPP"

1. PROPÓSITO GENERAL
-------------------
FICHAPP es una aplicación construida con Expo y React Native pensada para una gestoría y que gestiona 
el sistema de registro de la jornada laboral de trabajadores de varias empresas cliente
(modelo SaaS multiempresa).
Permite iniciar sesión, seleccionar empresas, fichar entradas, salidas, descansos y horas extra.,
ver el horario propio, solicitar vacaciones y reportar incidencias (olvidos de fichaje, etc). 
Adicionalmente ofrece soporte de roles: "user" para trabajadores normales y "admin" para un perfil de
administrador que puede ver el listado de empresas y sus trabajadores con sus horarios y sus fichajes 
en las empresas.

4. CONTEXTO DE USUARIOS: TrabajadorContext.tsx
-----------------------------------------
Este archivo define el contexto compartido entre las pantallas:
- trabajadorActual: datos del trabajador logueado.
- setTrabajadorActual: función para actualizar el trabajador actual.
- empresaSeleccionada: empresa sobre la que se trabaja actualmente.
- setEmpresaSeleccionada: función para cambiar la empresa activa.
- empresas: lista de empresas cargadas en la sesión.
- setEmpresas: actualiza la lista de empresas.
- seleccionarEmpresa: busca una empresa por id y la marca como seleccionada.

5. MODELOS DE DATOS
-------------------
5.1 Trabajador (src/models/trabajadores.tsx)
- id, dni, nombre, apellidos, dirección, email, password, puesto, cuenta de cotización.
- role?: "user" | "admin" para control de permisos.
- empresas?: ids de empresas asociadas.
- fichajes?: ids de fichajes registrados.
- horarios?: ids de horarios asignados.
- estado: usa la enumeración Estado para definir si está activo, descansando, etc.

5.2 Empresa (src/models/empresas.tsx)
- id, nombre, cif, direccion, poblacion, provincia, codigo_postal.
- trabajadores?: ids de trabajadores vinculados.

5.3 Fichaje (src/models/fichajes.tsx)
- id, idTrabajador, idEmpresa, tipo (entrada/salida/descanso/horas_extra).
- fecha: timestamp numérico.
- fecha_hora: objeto Date.

5.4 Horario (src/models/horarios.tsx)
- id, idTrabajador, idEmpresa, tipoJornada, dias, diasSemana.
- hora_entrada1, hora_salida1, hora_entrada2, hora_salida2.

6. SERVICIOS Y DATOS MOCK
-------------------------
Los servicios están implementados en src/services/* y usan datos de ejemplo de src/mock/*.
Este diseño simula un backend ligero dentro de la app.

6.1 src/services/empresasService.tsx
- obtenerEmpresas(): devuelve todas las empresas.
- getEmpresaById(id): busca empresa por id.
- crearEmpresa / editarEmpresa: funciones para crear y editar empresas en memoria.

6.2 src/services/trabajadoresService.tsx
- crearTrabajador(): genera un nuevo trabajador local.
- editarTrabajador(): actualiza campos del trabajador a partir de su dni.
- editarEstadoTrabajador(): cambia el estado del trabajador.
- getTrabajadorById(): busca trabajador por id.
- getTrabajadorByEmailYContraseña(): login por email y password.
- getUltimoFichajeTrabajador(): devuelve el último fichaje existente.

6.3 src/services/fichajesService.tsx
- crearFichaje(): registra un nuevo fichaje y lo asocia al trabajador.
- obtenerFichajesEmpresaTrabajador(): lista fichajes de un trabajador en una empresa.
- getFichajeTrabajadorEmpresa(): busca un fichaje por id dentro de una empresa/trabajador.

6.4 src/services/horariosService.tsx
- obtenerHorarioTrabajadorEmpresa(): devuelve el horario asignado de un trabajador para una empresa.
- obtenerHorarios(): devuelve todos los horarios.

6.5 src/services/shared/sharedService.tsx
- obtenerEmpresasTrabajador(): devuelve empresas vinculadas a un trabajador.
- agregarEmpresaATrabajador(): asocia una empresa a un trabajador y viceversa.
- obtenerTrabajadoresPorEmpresa(): devuelve los trabajadores vinculados a una empresa.
- obtenerHorariosPorEmpresa(): devuelve horarios de una empresa.

6.6 Datos mock de ejemplo
- trabajadoresMock.tsx: contiene a Manolo (user) y Angelita (admin).
- empresasMock.tsx: tres empresas de ejemplo, con trabajadores vinculados.
- horariosMock.tsx: horarios asociados a cada trabajador/empresa.
- fichajesMock.tsx: ejemplos iniciales de fichajes.

7. COMPONENTES REUTILIZABLES
---------------------------
7.1 ThemedText
- Componente que mejora <Text> de React Native.
- Soporta tipos: default, title, subtitle, link, defaultBold, defaultSemiBold.
- Usa el hook useThemeColor para obtener el color según el tema activo.

7.2 ThemedView
- Componente que mejora <View> de React Native.
- Permite aplicar colores definidos por tema y se usa como contenedor principal.

7.3 useThemeColor / use-color-scheme
- useThemeColor elige el color a partir del esquema de color activo (claro/oscuro).
- Colors se define en constants/theme.ts.

8. PANTALLAS PRINCIPALES
------------------------
8.1 app/index.tsx (VerPerfil)
- Controla cuatro estados de pantalla: inicio, registro, perfil y editar.
- `handleSignIn()` valida credenciales con `getTrabajadorByEmailYContraseña`.
- `handleRegister()` crea trabajador y establece sesión.
- `handleSubmit()` guarda cambios en el perfil del trabajador.
- Visualmente usa una tarjeta central con fondo oscuro, bordes redondeados y botones azules.
- La pantalla de Login muestra el formulario de email y contraseña.
- La pantalla de Registro agrega datos personales y campos para confirmar contraseña.
- La pantalla de Perfil muestra datos del trabajador y permite editar o cerrar sesión.
- La pantalla Editar permite actualizar campos del perfil.

8.2 app/(protected)/home.tsx
- Pantalla principal de fichaje después de seleccionar una empresa.
- Carga horario, último fichaje y permite fichar tipos:
  entrada, salida, descanso y horas extra.
- `handleFichar()` crea un nuevo registro de fichaje con `crearFichaje`.
- El estado `fichajeVersion` fuerza recarga cuando se registra un fichaje.
- Si el usuario es admin y hay empresa seleccionada, carga todos los trabajadores de la empresa.
- Calcula horas trabajadas hoy con `useMemo` usando la última entrada.
- Muestra una tarjeta de información con el saludo, horario, estado y último fichaje.
- Incluye botones para fichar y un enlace para cambiar de empresa.

8.3 app/(protected)/empresas.tsx
- Muestra las empresas disponibles y las empresas del trabajador.
- Si el usuario es admin, muestra todas las empresas y oculta la lista de empresas disponibles.
- Si el usuario es normal, permite añadir empresas disponibles a su lista.
- `handleSeleccionarEmpresa()` actualiza la empresa activa en el contexto.
- `handleSeleccionarDisponible()` asocia una empresa nueva al trabajador.
- `handleEliminarEmpresa()` elimina una empresa de la lista local de usuario.
- Usa tarjetas con fondo azul oscuro, bordes redondeados y botones de selección.

9. ESTILOS GENERALES Y DISEÑO
-----------------------------
La interfaz adopta una paleta profesional en tonos azul oscuro y cian:

- Bordes: #14436d

Las pantallas usan componentes con:
- bordes redondeados (`borderRadius: 16` o `24`)
- sombras suaves (`shadowOpacity`, `shadowRadius`, `elevation`)
- espaciado generoso (`padding: 16`, `marginTop: 16`)
- tipografías legibles y peso semibold para etiquetas.

10. ROLES Y PERMISOS
--------------------
- `role: "user"`: trabajador normal. Puede ver solo sus propias empresas, su jornada y fichar.
- `role: "admin"`: usuario administrador. Puede ver todas las empresas y su lista de trabajadores y sus jornadas.
- El rol se define al crear el usuario

11. FLUJO DE USUARIO
--------------------
1. El usuario abre la app en `app/index.tsx`.
2. Inicia sesión (**o se registra).
3. Tras el login, el perfil puede verse y editarse.
4. El usuario navega a `app/(protected)/empresas.tsx` para seleccionar o añadir una empresa.
5. Una vez seleccionada la empresa, accede a `app/(protected)/home.tsx` para fichar.
6. Si es admin, en `home.tsx` ve trabajadores de la empresa seleccionada.

12. LÓGICA DE NEGOCIO 
---------------------
- Empresas, centro de trabajo (de empresa), departamento (de centro de trabajo), 
calendario laboral (de una centro de trabajo) y festivos (de calendario)

- Fichajes (de trabajador, en centro de trabajo y dispositivo), dispositivos 
(para fichar, de centro de trabajo), tipos fichaje, motivos pausa (de empresa), 
permisos y politicas retencion (de empresa)

- Trabajadores (de empresa), usuarios (de trabajador y empresa), usuarios roles 
(id rol, de usuario y empresa), roles, turnos (de empresa) y resumen jornada 
(de trabajador, empresa)

Se crean las empresas, los centros de trabajo de cada una, los departamentos de 
cada una, la auditoria accesos (de empresa, usuario, trabajador), el calendario 
laboral de cada una y sus festivos en el calendario, los trabajadores ligados a 
cada empresa, un usuario por cada trabajador, los tipos de roles y los roles 
asignados a cada usuario, las asignaciones de turnos (de trabajador y turno), 
los turnos en las empresas, los tipos de fichaje, los motivos de pausa en la 
empresa, los permisos, la politica retencion y dispositivos.
